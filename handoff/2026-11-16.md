## Station flow now (Gateway 12)
Label > "already passed?" (Skip it / Test again) > Login > Model/Serial/MAC (device info
call; Network map only if it does not match) > IMEI > SIM > 5G > Wi-Fi 2.4/5/6 > Wi-Fi name >
Factory reset > [IMEI / SIM / 5G after reset, one login, only those that failed before] >
Ping (only when SIM and 5G pass) > [Wi-Fi name after reset] > Visual.
A failure before the reset that the reset can fix (IMEI not readable, SIM, 5G, Wi-Fi name)
is INFO; the reading after the reset counts. Tests: 93 pass on Linux.
